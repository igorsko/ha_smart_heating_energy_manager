# Dashboard reference layout

The overview follows the supplied reference: five KPI cards, ranked generators, compact zones, tariff panel, thermal model, PV and battery, historical temperature/demand graphs and quick navigation. Responsive CSS uses the Home Assistant theme. Native sidebar is preserved. History uses the authenticated Home Assistant REST history endpoint for the last 24 hours, refreshed at most every five minutes per entry. Missing history is explicitly shown; no synthetic samples are used. The price chart is marginal electricity cost, not PUN unless a separate PUN series is later configured. Thermal calibration reports measured fit residual (RMSE), not an invented confidence percentage. Generator and model quick actions navigate to actual sections; manual recalibration is not yet exposed. Live Home Assistant rendering and history permissions remain to be verified.
