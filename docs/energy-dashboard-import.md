# Home Assistant Energy dashboard import

Smart Heating reads EnergyManager.data every 15 minutes through Home Assistant's energy data manager, without modifying Energy preferences. Configured solar, grid and battery sources are imported automatically; existing manual PV power, export and SOC mappings take precedence. Supports multiple PV sources, signed grid and battery power, legacy grid power arrays, inverted or paired power sensors and capacity-weighted battery SOC when available. Energy statistics identifiers and solar forecast configuration IDs are retained for future processing. Cumulative kWh counters are never presented as instantaneous kW. If only energy counters are configured, current power remains unknown. External statistics and solar forecast values are not queried yet. The manager API was checked against upstream Home Assistant Core dev on 2026-11-27; live runtime testing is still required.
