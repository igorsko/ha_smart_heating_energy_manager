# Persisted thermal model

The last validated Recorder fit is saved in Home Assistant local storage per configuration entry. Manual heat loss remains the default. Enable Use learned heat loss to apply a valid saved H to demand calculations. C and aggregate COP are diagnostic only; they are not applied to individual heat pumps. Lock calibration updates to preserve the previous result. Invalidate previous calibration to change the generation and prevent reuse; unlock and enable history to learn again. Changing generator configuration or temperature mapping invalidates the saved fit. A failed calibration does not overwrite the last valid result. No appliance commands are issued. Fit quality is conditional on data coverage and unmodelled heat gains. Home Assistant runtime tests remain pending.
