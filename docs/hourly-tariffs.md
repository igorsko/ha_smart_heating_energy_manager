# Hourly tariffs

For explicitly enabled indexed tariffs, the selected or uniquely discovered index sensor may provide timestamped hourly records through prices, forecast, hourly_prices, raw_today or raw_tomorrow attributes. Each record needs an explicit timezone-aware hour start and price with supported currency/energy unit. Optional end must be exactly one hour later. Positional arrays and ambiguous timestamps are rejected. Contract components are applied to every index value. Missing hours use the existing current tariff fallback, individually labeled in the forecast. Fixed contracts are not changed. Joint planning evaluates hourly import costs; battery dispatch remains greedy solar-only, terminal stored energy valued at the current tariff, and thermal dispatch remains steady-state. Provider-specific payloads not matching these formats require an adapter. No direct testing against the user's PUN integration has been performed.
