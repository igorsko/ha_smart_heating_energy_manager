# Joint energy planning (0.2.1)

Enable in integration options. Enter average household base load excluding heating and DHW, export remuneration and battery parameters if applicable. Capacity and state of charge may be imported from Energy. The planner evaluates contiguous DHW heating windows against a fixed space-heating schedule, using hourly PV estimates, a constant import tariff, a constant export tariff and greedy solar-only battery charging/discharging. Terminal stored energy is valued at the current import tariff to reduce end-of-horizon bias. No grid charging or device control. Reserve, charge/discharge power and one-way efficiency are explicit. Missing data suppresses advice instead of assuming zero. This is a scenario estimate, not global optimization: no thermal inertia dispatch, hourly future tariff, instantaneous power constraint, learned household load, hot water draw-off or sanitation scheduling yet. Actual runtime verification remains necessary.
